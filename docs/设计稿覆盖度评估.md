# 设计稿覆盖度评估

> 对象：`enterprise-design-system` skill 的标志性设计稿（`assets/screenshots/` 15 张，覆盖菜单/维修/出差/用印/接待/用车/文件管理/人员资料等典型页面）
> 基准：现有 35 个 `m-*` / `external-*` 组件 + `styles/theme` 令牌体系
> 结论日期：2026-10-12

## 0. 一句话结论

**骨架能覆盖约 6 成，细节还原不了。** 三个层面的缺口：

1. **8 个组件完全缺失**（底部标签栏、自定义导航、附件方块、文件列表、选择页、账号卡、明细卡、统计图）；
2. **一批令牌色差**（成功绿/警告橙/浅蓝底/分隔线/输入底色，以及品牌蓝——品牌蓝已裁决保留 `#5192FF`）；
3. **12 处组件级偏差**（列表卡字重、标签描边、步骤条完成态、时间轴圆点、弹窗宽度、审批按钮实心/描边、上传形态等）。

> 说明：下表「设计稿要求」摘自 `references/design-system.md` §2–§6；「现状」为实际读码结论。

## 五、若要 100% 还原设计稿的优先级建议

**P0（结构性缺失，不补则无法出稿）**
1. 新建 `m-navbar`、`m-tabbar`、`m-file-upload`、`m-file-item`、`m-select-list`、`m-account-card`、`m-detail-card`（7 个）。
2. `m-tag` 增加**灰档**；`m-step` 修正**完成态 + 末步勾逻辑**；`m-button-process` 的「拒绝」改**实心橙**。
3. 同步 `App.vue` / `pages.json` 的 `#F5F9FC` → `#F5F7FB`。

**P1（色与非色令牌收口）**
4. 成功绿 `#00B578`、警告橙 `#FF7A00`、浅蓝底 `#EAF2FF`、分隔线 `#EBEEF5`、输入底 `#F7F8FA` 对齐 skill；`$gray-200` 拆出独立「描边灰 `#D9D9D9`」令牌；品牌蓝按裁决**保留 `#5192FF`**。
5. `m-popup` 宽度（屏宽 − 48px）、标题（14px `#999999` 左上）、内置底部按钮区。
6. `m-upload` 改为附件方块语言（或新增专用件）；`m-banner` 渐变方向/色/字号。

**P2（观感微调）**
7. `m-card` 标题字重改 Medium、补 meta 行；`m-tabs` 字号 15px / 下划线 3px；`m-fab` 支持文字；`m-trans` 圆点放大到 24rpx、补「办理中」标签与卡片包裹；`m-form-item` 行高下调至 88–96rpx；`m-radio` 增加 `direction`。
